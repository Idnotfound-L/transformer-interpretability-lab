# Results archive — version-separated

This folder deliberately separates two experiment protocols:

- `protocol_v1/`: complete older raw run outputs that were available (GPT-2 seed 7; SmolLM3 seeds 7, 13, and 29), plus a separately labeled SmolLM3 smoke test. These are exploratory/legacy results.
- `protocol_v2/`: corrected-protocol raw bundles for GPT-2 and SmolLM3-3B-Base, seeds 7, 13 and 29, plus a consolidated SmolLM3 summary.

**Never pool the V1 and V2 runs.** V2 is the corrected protocol and should be the primary basis for current project claims. The older V1 archives are retained so the research history is reproducible and auditable. See each version's README for detailed availability notes.
